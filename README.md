# Habitat · Tu caso

Aplicación web (PWA) de asesoría previsional para AFP Habitat: muestra costo, rentabilidad y servicio de forma visual, pensada para usarse en pantalla completa en celular, tablet o computador.

## Contenido
- `index.html` — la aplicación completa
- `manifest.webmanifest` y `sw.js` — instalación como app y uso sin conexión
- `img/` y `fonts/` — logos, íconos y tipografías (Rubik, Public Sans)

## Uso
Abrir `index.html` en un navegador, o publicar la carpeta con GitHub Pages.
